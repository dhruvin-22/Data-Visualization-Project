# Data Visualization Project

## Overview
This project focuses on creating interactive data visualizations using the D3.js library. It displays various charts (Bar Chart, Pie Chart, Line Chart, etc.) based on FIFA World Cup data and visualizes key statistics in an engaging way.

- **D3.js** - A JavaScript library for creating dynamic, interactive data visualizations in web browsers.
